## 三、本轮用户视角走查发现并修复的问题

1. **管理员无法浏览/只读进入他人空间**：工作空间页只列“我加入的空间”，而“管理员只读查看”只出现在自己已加入的空间上（真实用户场景完全用不上）。
   → 新增管理员「全部空间」区块（后端 `GET /workspaces/all`，最新优先，最多展示 20 个 + 总数提示），可对任一空间发起只读查看。
2. **只读横幅把页面布局挤乱**：横幅被插在内容横向 flex 行里，导致左侧变成一大块黄色、内容被推到右侧。
   → 横幅移到顶栏下方、内容区之上，整宽显示。
3. **只读视图刷新后静默丢失**：`viewWorkspace` 未持久化，刷新/整页跳转后横幅消失且请求头丢失（写保护形同虚设）。
   → 写入 zustand persist 并在水合时恢复 `X-Workspace-Id`。
4. **创建空间后“看不见”新空间**：列表按名称排序且默认折叠，新建空间可能落在折叠区外，用户以为没创建成功。
   → 创建成功后自动切换到新空间（token 重签 + 缓存清空），并自动展开列表、置顶显示；右下角提示“已创建，已切换到新空间”。
5. **操作反馈不在视线内**：提示只渲染在“我的工作空间”卡片底部，在成员/迁移区操作时看不到结果。
   → 统一改为右下角浮层提示（成功/失败 4s 自动消失），跨卡片操作都能看到。
6. **当前空间不直观**：切换后只靠行内徽章，列表长时看不到。
   → 卡片顶部新增「当前使用：空间名 + 角色」概览；空间列表当前空间置顶并高亮。
7. **角色中英混杂**：空间行/成员行显示 `owner/member/admin`。
   → 统一为「所有者 / 管理员 / 成员」；顶栏切换器角色同步中文化并加宽避免截断。
8. **全部空间里平台空间徽章重复**（名字已叫“平台空间”，又挂一个“平台空间”徽章）→ 去重。

## 四、当前仍存在的产品/交互优化点（非隔离缺陷）

1. 「全部空间」最多展示 20 个、无搜索/筛选；空间多时（如测试库 60+）需要分页或搜索框（真实用户量下影响小）。
2. 顶栏空间切换器是原生 `<select>`，空间很多时体验一般（可升级为带搜索的下拉面板）。
3. 只读视图下顶部横幅已提示写操作会被拒，但页面上的“新建”按钮仍是可点状态（点击后由服务端 403 + 表单错误兜底），可进一步置灰。
4. 创建空间自动切换是当前产品决策；若希望“创建不切换”，改一行即可（`handleCreate` 去掉 switchWorkspace）。
5. 普通用户空间很多时列表默认折叠 6 个 + 展开全部；真实场景一般 1~3 个。

## 四之二、新增：创建用户选择空间（2026-11-13）

- 路径：管理员登录 → 新建一个空间 → 系统管理 → 用户管理 → 新增用户 → 填用户名/邮箱/密码 →
  「所属空间」选择该空间 → 「空间角色」选“空间管理员” → 创建。
- 结果：✅ 弹窗展示空间下拉与空间角色；创建成功后列表出现新用户；新用户登录后当前空间即所选空间。
- 截图：`17-管理员-新增用户选择空间.png`、`18-管理员-已创建并加入空间的用户.png`。
