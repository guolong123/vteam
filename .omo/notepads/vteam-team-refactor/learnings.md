## 2026-09-01 — Task 1 expand-contract schema (Sisyphus-Junior)
- **Finding**: expand 阶段必须保持 Task.teamId / ChatChannel.teamId / Session.teamMemberId / Message.taskId 全部 nullable，且 ChatChannel.taskId 由 required 改 nullable 以实现 Task→Team 归属过渡；contract 阶段再改 NOT NULL 并删旧列，单步直接删约束不可回滚。
- **Prefix lock**: Team tm_/TeamMember tmm_/TeamQueue tq_ 与现有 ta_/c_/t_ 等零填充 10 位前缀一致，通过 IdGeneratorService seed 对齐；version 乐观锁字段 @map("version") 必须与业务层 CAS 双保险（FOR UPDATE + version increment）配套。
- **Index necessity**: Message 的分区索引必须双建 @@index([taskId,createdAt]) (按任务时间拉取) 与 @@index([channelId,taskId]) (按频道+任务分区)，TeamQueue 必须 @@index([teamId,position]) 保证 FIFO 扫队性能；缺一即触发全表扫描。
- **Prisma MySQL expand trick**: ChatChannel.teamId @unique nullable 在 MySQL 允许多 NULL，过渡期不阻塞存量行；migrate 时需先 CREATE TABLE teams 再 ADD COLUMN team_id FK，避免引用未建表；本机无 DB 时用 --create-only 失败属预期，改手工生成 migration.sql 并以 prisma validate 作为等价校验。

## 2026-09-01 — Task 2 TeamsModule CRUD (Sisyphus-Junior)
- **Finding**: Teams 全局唯一 name 必须 DB @unique + 服务层预检 409 双保险，预检防友好提示、DB P2002 兜底并发竞态；成员 seq 必须事务内 `SELECT MAX(seq) FOR UPDATE` 行锁（`$queryRawUnsafe` 显式 FOR UPDATE），aggregate 仅作 sqlite 测试 fallback，否则并发创建同 agent 多实例会重号触发 uk_team_members_team_agent_seq 冲突。
- **Alias/WorkDir**: alias 缺省 `ROLE_LABELS[role] ?? agent.name` + `-seq`，workDir 缺省 `sanitizeWorkDirName(agent.name)` + `-seq`（seq>1），与 tasks.service.defaultAlias/defaultWorkDir 同源（抽离 work-dir.util 避免循环依赖）；多实例同 agent 场景必须验证两行 seq 1/2 且 workDir 递增。
- **Version乐观锁**: Team.version 乐观锁通过 `updateMany where {id, version}` CAS + `increment:1` 实现，冲突 409 VERSION_CONFLICT；成员增删改联动 `team.update {version increment}` 触 updatedAt，广播 TEAM_CHANGED 前后一致；创建时 version=0，PATCH 未传 version 时走普通 update 仍 increment。
- **Idle删除**: DELETE 仅当 `currentTaskId == null && queues.length==0` 放行，否则 409 TEAM_BUSY / TEAM_QUEUE_NOT_EMPTY；queue 为 TeamQueue FIFO 索引，空闲判定不涉 task.teamId 扫描，交由调度层保证 currentTaskId 及时清零。
- **权限矩阵**: 新增 teams 资源到 PERMISSION_RESOURCES（10 域），member 角色预置 `teams:{view:true,create:true,edit:true,delete:false}`，admin 全放行（all:true）；Guard 叠加 JwtAuth 全局 + PermissionGuard `teams:view/create/edit/delete`，验证 curl 401 未鉴权、403 缺权限。
- **Evidence**: server/src/teams/*（teams.service/controller/module + 4 DTO + 2 spec），server/src/users/roles.constants.ts + prisma/seed.ts 增 teams 域，tsc 绿、teams.service.spec 18 绿（覆盖创建/重名409/同agent两行/忙删409/alias/workDir/FOR UPDATE）
