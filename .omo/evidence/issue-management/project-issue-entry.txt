# Project Card「Issue 管理」入口 — 验证证据

## 需求
项目列表页的项目卡片上增加「Issue 管理」入口链接（nav 有 ☰ 入口但项目卡片没有直达链接）。

## 改动（web/app/(main)/projects/page.tsx）
1. `ProjectCard` props 增加 `onIssues?: () => void`（仿 onArtifacts，JSDoc 标注 stopPropagation 防卡片主跳转）
2. 次级入口区（产出物按钮旁，L231-256）新增「Issue 管理」按钮：
   - data-testid="project-issues-entry"
   - onClick: `e.stopPropagation(); onIssues?.();`
   - 样式与产出物按钮一致（padding xs/sm+2、radius.pill、border neutral[200]、bg #FFFFFF、color neutral[600]、fontSize xs、fontWeight 500）
   - 图标 ☰
3. 使用处（L732 附近）加 `onIssues={() => router.push(`/issues?pid=${p.id}`)}`
