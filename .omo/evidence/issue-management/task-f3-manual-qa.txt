## 发现的 UI 缺陷（1 项，已修复）

### cmd-panel.tsx DEFAULT_CMDK_ITEMS 缺「Issue 管理」导航项（Minor，已修复）
- 现象：Cmd+K 命令面板的「导航」组没有「Issue 管理」入口，搜索 "Issue" →「无匹配命令」。
  而左侧 Dock（nav-dock NAV_ITEMS）有该入口，`CMDK_NAV_PATH`（app-shell.tsx:142）也含 `"Issue 管理": "/issues"`。
  根因：`web/src/components/layout/cmdk-panel.tsx` 第 44-57 行 `DEFAULT_CMDK_ITEMS` 数组遗漏该导航项，
  命令面板的「导航」组直接由该数组渲染（app-shell cmdkItems 过滤只做权限过滤，不补缺失项）。
- 影响：命令面板与 Dock 导航不一致；用户无法通过 Cmd+K 搜索跳转 Issue 管理（需经项目内进入）。
  不影响 issue CRUD 主流程，故定级 Minor。
- 修复：在 DEFAULT_CMDK_ITEMS「导航」组首项「切换项目」后插入 `{ group: "导航", label: "Issue 管理", icon: "☰" }`。
- 验证：
  - `web/npx tsc --noEmit` → 0 错误
  - 重新构建 docker 镜像 `aiagents-web` + `docker compose up -d web` → web 200
  - 真实浏览器重测：Cmd+K 面板显示「Issue 管理」，搜索 "Issue" → MATCH，点击可跳转（无 pid 时按步骤2 重定向 /projects，行为正确）
- 说明：playwright e2e 全部失败系环境问题（playwright.config.ts baseURL 为 localhost:3001，本地无 3001 dev server；web 实际跑 docker 13001），与本次改动无关。
