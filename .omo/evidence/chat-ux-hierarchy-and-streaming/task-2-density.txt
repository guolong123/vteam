7. 计算校验：800 / 10 / 2000 / 200（绿跑实测）
======================================================================
A1 正文（900 字符夹具，e2e 实测快照）:
  折叠态 { lineClamp: "10", maxHeightStyle: "16em", lineHeightRatio: 1.6,
           maxHeightInLines: 10, visibleLines: 10, toggleAria: "false" }
  - 16em ÷ (1.6 × fontSize 13px) = 208px ÷ 20.8px/行 = 10 行 ✓（与 clamp 10、实际裁剪高度 10 行一致）
  - 800 < 900 → toggle 出现；800 = 800（严格大于不触发）→ toggle 计数 0 ✓
  展开态 { lineClamp: "", maxHeightStyle: "", lineHeightRatio: 1.6,
           beyondClippedHeight: true, toggleAria: "true" }，文案 展开 ▼ ⇄ 收起 ▲ ✓
A2 tool（3000 字符夹具）:
  字符串路径：折叠/展开 hasFirst2000=true、hasAfter2000=false、exactFirst2000Span=true、titleLen=2000
    → DOM 恰好含前 2000 字符，第 2001..3000（1000 字符）完全缺席，title 属性 ≤2000
  JSON 路径：折叠 summary/title = JSON.stringify({...}).slice(0,2000)（titleLen 2000）；
    展开 input/output 两个 span 各恰好 2000，序列化第 2001 字符起缺席
A3 thinking（3000 字符夹具）:
  折叠 { excerptLen: 200, excerptIs200: true, titleLen: 2000, titleIs2000: true,
         hasAfter2000: false } → 201..3000 共 2800 字符缺席（含 title 属性）
  展开 { hasExact2000Div: true, hasAfter2000: false, titleLen: 2000 } → 展开内容恰好完整 2000 字符，
    第 2001 字符起不进 DOM
纯检查侧（lib-unit）: caps=[2000,2000]（字符串+JSON 两路径）、caps=[200,2000]、
  clampLines=1、threshold=800、lineClamp=10、maxHeightEm=16、16/1.6=10 ✓
夹具唯一性：CJK 连续码点（0x4E00/0x5000/0x6000 起），slice(2000) 不可能包含于 slice(0,2000)，
  「第 2001 字符起不出现」断言无假阳性。
