3. 实现（仅本 todo 的产品/测试文件）
======================================================================
新增
  web/src/components/ui/message-identity.tsx
    纯展示组件 MessageIdentity({ author, role, time, senderType, initials, style, className })：
    一次渲染 AgentAvatar(s/sm/dot=false) + `chat-bubble-author`（12px/600，roleText 取色，
    author 缺省回落角色标签，external 徽标）+ `chat-bubble-time`（11px，`· HH:MM`，与作者同级兄弟，
    不嵌套）。不读原始 id、不访问业务映射/数据源；role 仅用于 theme/tokens 取色。
    新增 testid：`message-identity`（身份栏容器，仅此一个新 testid，见 §5）。
  web/src/components/ui/index.ts  → 导出 MessageIdentity + MessageIdentityProps。

改动
  ui/chat-bubble.tsx    新增 `showIdentity?: boolean`（默认 true）；false 时跳过自身 AgentAvatar
                        与身份行（mention 徽标、正文、折叠、附件均不受影响）。页面级独立气泡
                        （user/system/external/无 part 的 agent）未传该 prop → 行为不变。
  chat/msg-parts.tsx    顶部渲染唯一 MessageIdentity；过程片段 + 正文/附件 收进 `secondaryRows`
                        （左缩进 36 = 头像 28 + 间距 8，对齐身份栏文字列）；
                        正文与附件两条 ChatBubble 调用传 `showIdentity={false}`；
                        aborted 分支 = MessageIdentity + MsgAborted（各一次身份）；
                        无任何可渲染内容时不渲染身份栏（保持空消息不占位）；
                        不再向 MsgThinking/MsgTool/MsgError/MsgAborted 传 author/role/time。
  chat/msg-thinking.tsx 移除 AgentAvatar、author、time（pending 仍显示「思考中…」）；
                        props 收敛为 { state, text, style, className }；A3 两处 .slice 截断原样保留。
  chat/msg-tool.tsx     移除 AgentAvatar、摘要行 time、展开面板作者/时间 footer；
                        props 收敛为 { name, status, input, output, style, className }；I/O 2000 封顶不变。
  chat/msg-error.tsx    移除 AgentAvatar 与 author；保留可选 `time`（session/page.tsx:1391 独立状态行
                        在传，该文件本 todo 不允许改动 → MsgParts 不再传 time，消息内时间只来自身份栏）。
  chat/msg-aborted.tsx  移除 AgentAvatar/author/time，文案改为「处理被用户中断 — {detail}」；
                        props 收敛为 { detail, style, className }。
测试
