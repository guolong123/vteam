3. 实现要点（可测边界）
======================================================================
web/lib/date-separator.ts（纯函数，不依赖组件与运行环境）
  localDateKey(value)        非字符串/空串/不可解析 → null（不抛异常）；否则
                             `${getFullYear}-${pad(getMonth+1)}-${pad(getDate)}`（浏览器本地时区）
  dateSeparatorFlags(list)   返回长度 === list.length 的 boolean[]；
                             仅当「当前条日键」与「上一个已知日键」都非 null 且不同时为 true；
                             时间缺失/非法的条恒为 false，且不清空已累积日键
                             → 单日列表零分隔、首条缺失不在顶部插分隔、跨缺失行的跨天仍分隔
  formatDateSeparatorLabel   "2026-09-21" → "2026/09/21"
page.tsx
  const dateSeparatorFlagsByIndex = dateSeparatorFlags(messages);   // 在 messages 定义之后
  withSeparator(node)：separatorKey === null 时原样返回 node（key 仍是 msg.id，行为与 B2 完全一致）；
    否则返回 <React.Fragment key={msg.id}> + 分隔 div + node —— 只做插入，不排序、不过滤。
  分隔条：position sticky / top 0 / zIndex 1 / backgroundColor neutral[50]（与中央聊天区同色，
    滚动吸顶时不透字）、hairline flex:1 + 11px 中性文字、margin 4px 8px、data-date-key。
chat-bubble.tsx system 分支
  根：display flex + justifyContent center + margin 4px 8px（正文行 margin 0，只吃列表 16px gap）
  内：独立样式（不再 spread bubbleBase）：padding 4px 12px、border 1px dashed neutral[200]、
      borderRadius pill、backgroundColor neutral[100]、color neutral[500]、
      fontSize messageFontSize.meta(11)、lineHeight 1.5、textAlign center
  保留 data-testid="chat-bubble" data-type="system"；全文渲染，无 clamp / 无 toggle / 不隐藏。
