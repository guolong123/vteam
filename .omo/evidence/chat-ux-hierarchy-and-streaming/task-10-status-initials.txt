3. 实现要点
======================================================================
lib/message-initials.ts
  messageInitials(name: unknown): string | undefined
    1. 非字符串 / trim 后为空 → undefined
    2. RAW_SENDER_ID_PATTERN（display-author 导出的同一正则）命中 → undefined（B9 双保险）
    3. 首码点 ∈ CJK（U+3040-30FF 假名、U+3400-4DBF/4E00-9FFF 汉字、U+F900-FAFF 兼容、
       U+1100-11FF/U+3130-318F/U+AC00-D7AF 谚文、U+20000-2A6DF 扩展 B）→ 返回该单码点
    4. 否则按码点扫描，取前两个 \p{L} 字母各自 toUpperCase()（扩张字形如 ß→SS 保留原字形，
       恒 ≤2 码点）；一个字母都没有 → 首码点 toUpperCase()（名字派生，不回角色字母）
    非全局正则 + Array.from(按码点) → 无 lastIndex 状态残留、不拆代理对。
    注：裸 id 判定用正则而非 isRawSenderId 谓词——对已是 string 的值做 `value is string`
    反向收窄会把剩余分支压成 never（tsc 实测，见红证据 §1）。
chat-bubble.tsx
  userMessageStatus(status)：逐值白名单（sending/sent/failed），不走 `in`（避原型链误命中）
  → { key, label } | null；仅 isUser 且非 null 才渲染。
  标记节点：data-testid="chat-bubble-status" data-status role="status"，
  fontSize=messageFontSize.meta(11px)、color=neutral[400]（failed → #DC2626）、
  位于列布局末位（气泡体之后）→ 文档流兄弟节点，无 position/z-index，不覆盖不挤压正文。
  头像：<AgentAvatar role initials={initials} …>（未传时 AgentAvatar 内部回落角色字母）。
session page.tsx
  author = resolveDisplayAuthor([instanceNameById(senderInstanceId), agent.name, memberHit.name])（B5/B9 原样）
  → const initials = messageInitials(author)（唯一生产调用点）
  → external ChatBubble / MsgParts / 兜底 ChatBubble 三处透传；兜底处另加 status={msg.status}
    （user 消息唯一渲染入口；system 分支与 session-status 行一行未动，B4/B12 语义不变）。
身份边界：user 消息 author 恒 undefined（senderId 为 u_*，三路映射全落空）→ 无身份、无头像、无缩写，
只有状态标记；agent 消息不渲染状态标记（实测 statusMarkerOnAgent=0）。
