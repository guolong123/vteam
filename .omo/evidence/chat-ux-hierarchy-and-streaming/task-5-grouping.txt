3. 实现要点（可测边界）
======================================================================
web/lib/message-grouping.ts
  export const MESSAGE_GROUP_MAX_GAP_MS = 5 * 60 * 1000;   // 恰好 5 分钟成组，5 分 + 1ms 不成组
  isGroupedWithPrevious(previous, current) 依次判定:
    1) previous/current 都存在
    2) 两条 senderType === "agent"（user/system/external 任一侧即 false）
    3) senderId 为字符串且非空、两者相等（""、null、字段缺失即 false）
    4) 两条 createdAt 可解析（缺失、""、非法串即 false）
    5) 本地日历日相同（new Date 的 getFullYear/Month/Date，跨日即 false）
    6) |Δt| <= MESSAGE_GROUP_MAX_GAP_MS
  谓词成对语义：是否与「上一条」成组由调用方 messages.map((msg, index)) 的 index+1 决定，
  谓词本身不排序、不读数据源、不做链式回溯。
page.tsx: `messages.map((msg, index) => …)` 内
  `const grouped = isGroupedWithPrevious(index > 0 ? messages[index - 1] : undefined, msg);`
  仅 agent 分支的 <MsgParts … grouped={grouped} /> 消费；external/user/system 分支不接该 prop。
msg-parts.tsx: grouped=true 时不渲染共享 MessageIdentity（aborted 分支与主分支两处），
  secondaryRows 的 paddingLeft:36 不变 → 分组行与上一条正文左对齐；正文/过程/流式渲染路径不变。
