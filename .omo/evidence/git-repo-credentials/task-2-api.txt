### 3.1 POST 创建（SSH 私钥 + 授权 a_tester read/allow）
```
POST /api/v1/git-repos
{repoUrl:"git@gitee.com:xishuhq/test-repo.git",authType:"ssh_key",
 key:"-----BEGIN OPENSSH PRIVATE KEY-----\nMOCK\n-----END OPENSSH PRIVATE KEY-----",
 grantedAgents:[{agentId:"a_tester",permission:"read",effect:"allow"}]}
→ 200 {
  "id":"gc_0000000001","repoUrl":"git@gitee.com:xishuhq/test-repo",  # 去 .git
  "authType":"ssh_key","fingerprint":"----****----",                  # 脱敏
  "revokedAt":null,"createdAt":"2026-08-12T03:43:30.832Z",
  "grantedAgents":[{"agentId":"a_tester","name":"测试","permission":"read","effect":"allow"}]}
key 明文泄漏检查：响应 grep MOCK → 0 命中
```

### 3.2 GET 列表
```

### 3.3 唯一约束 & 参数校验
```
重复 POST 同 repoUrl+authType → 409 REPO_EXISTS

### 3.4 DB 落库（AES-256-GCM 密文 + fingerprint，无明文）
```
mysql> SELECT id,repo_url,auth_type,LEFT(credential_ref,20),fingerprint,created_by,revoked_at FROM git_credentials;
gc_0000000001  git@gitee.com:xishuhq/test-repo  ssh_key  282fda820ee1fcb0e509  ----****----  u_admin  NULL
mysql> SELECT id,agent_id,repo_url,permission,effect,granted_by,revoked_at FROM git_repo_grants;
gr_0000000001  a_tester  git@gitee.com:xishuhq/test-repo  read  allow  u_admin  NULL
```

### 3.5 DELETE 软撤销
```
DELETE /api/v1/git-repos/gc_0000000001 → {"id":"gc_0000000001","revokedAt":"2026-08-12T03:44:04.961Z"}
再次 GET → []
DB：git_credentials.revoked_at 与 git_repo_grants.revoked_at 均已置（凭证+授权双软撤）
已吊销 id 再 DELETE → 404
```

### 3.6 PATCH 重加密 + 授权全量覆盖（补充冒烟）
```
POST https_token 仓库 → write 授权缺省 effect → ask（write→ask 缺省生效）
PATCH {key:"ghp_updatedtoken123",grantedAgents:[{agentId:"a_developer","permission":"read"}]}
→ fingerprint 更新为 ghp_****n123；grantedAgents 全量覆盖为 a_developer read/allow
DELETE 清理 → []（测试数据已清理）
```
