【UI 缺陷/观察项】
---------------------------------------------------------------------
严重级别说明：均为「观察/信息」级，无 P0-P2 缺陷。
- [观察] HTTPS token 无真实性校验：占位 token 可保存成功（平台无法远程校验 token
  有效性，token 在 git 操作时由远端验证）。建议后续迭代可加「保存时可选连通性探测」，
  非本计划范围（17 篇 §3.4 明文零接触约束下不做回调探测）。
- [观察] worker 凭证清空依赖心跳周期（~30s）：DELETE 后 worker 文件延迟约一个心跳
  周期才归零（06:21:27 删除 → 06:21:33 清空）。异步架构设计行为，非缺陷；若需即时
  可调小心跳间隔。
- [既有遗留] task-5 §8 记录的 <900px 窄视口 NavDock(z-50) 遮挡弹窗(z-40) 问题仍存在，
  真实浏览器 1440px 视口下无影响，非本次 F3 范围。
