风险/备注
---------
- 任务描述契约写 PATCH /tasks/:id/team，实际后端为 POST（T2 实现）；前端按实际后端 POST 调用
- 别名仅显式输入才提交，缺省由服务端生成（与创建页 T5 提交契约一致）
- 新实例在 in_progress 任务 joinStatus=active（后端 T2 语义），前端无需处理
- GET /agents 失败/未返回时回退 seed 预置 agent id（a_product 等），添加不中断
