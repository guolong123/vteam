七、Risks
----------------------------------------------------------------
- fileRef 语义差异：用户上传归档的 filePath 为落盘 URL（/uploads/<UUID>.<ext>），
  而 Agent MCP 上传仍为 worker 原始路径（如 /tmp/opencode/req.md）——read_file
  匹配逻辑（normalizeFileRef）对两者均兼容，行为不变
- 上传归档为 await 同步执行（成功/失败都返回上传结果），上传响应略慢于纯上传
  （一次 DB 写入），换取真实链路时序确定性
- 归档失败不阻断上传（warn），附件发送稳定性优先
- 未 git 提交（未授权）
