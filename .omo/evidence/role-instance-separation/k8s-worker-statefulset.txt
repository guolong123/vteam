[0] 背景 / 根因
--------------------------------------------------------------------------------
- worker 原为 Deployment，多副本共享同一 home PVC（vteam-worker-home，
  opencode.db SQLite 会话库 + auth.json 凭证）→ 多副本并发写 SQLite 损坏
  （上次 mcp 修复时发现 "Tree 23 page 23 Extends off end of page"，临时降 1 副本）。
- 目标：worker 迁 StatefulSet + volumeClaimTemplates（每副本独立 PVC），
  从架构上消除共享卷并发写。

[1] chart diff（chart/vteam/）
--------------------------------------------------------------------------------
a) templates/deployment-worker.yaml → 删除，新建 templates/statefulset-worker.yaml：
   - kind: StatefulSet；spec.serviceName: <release>-worker-headless
   - replicas/podManagementPolicy: OrderedReady；updateStrategy.type: RollingUpdate
     （values.worker.updateStrategy.partition 空 → 不渲染 rollingUpdate 子块，全量滚动）
   - env/探针/镜像/资源与原 Deployment 完全一致：
     X_WORKER_TOKEN(secret)、HOME=/root、WORKER_ID=w_$(POD_NAME)（downward API，
     StatefulSet pod 名 <release>-worker-<ordinal> 全局唯一）、extraEnv
   - volumes 改为 volumeClaimTemplates（worker-home→/root、worker-work→/data/keta-worker，
     RWO + size + storageClass(空=集群默认)）；持久化 enabled=false 时回退 emptyDir
b) templates/service-worker-headless.yaml（新增）：
   clusterIP: None，selector 同 worker 标签，port 4000/serve（StatefulSet serviceName 必填）
c) templates/pvc.yaml：移除 worker-work/worker-home 段（仅保留 uploads）
d) templates/configmap.yaml：注释 WORKER_ID 下发说明 Deployment → StatefulSet（无功能变化）
e) values.yaml：
   - worker 段新增 persistence.workerHome(5Gi)/workerWork(10Gi)/updateStrategy.partition
   - 顶层 persistence 移除 workerWork/workerHome（保留 uploads/mysql）
f) values-dev.yaml：worker.persistence.* 随迁；README.md 更新（结构/持久化表/关键 values/
   compose 对齐点 WORKER_ID 与挂载说明）

[3] 部署：helm upgrade（REV 8）
--------------------------------------------------------------------------------
- init Job 已被 TTL 清理（kubectl get job 空），无需手动删除。
- ⚠️ --reuse-values 触发 nil（新值 worker.updateStrategy.partition 未被旧 user-values
  携带，helm --reuse-values 不复用新 chart 嵌套默认值）。改用：
  helm get values vteam -n vteam | tail -n +2 > /tmp/opencode/vteam-current-values.yaml
  helm upgrade vteam chart/vteam -n vteam \
    -f /tmp/opencode/vteam-current-values.yaml \
    --set replicaCount.worker=2 \
    --set worker.persistence.workerHome.size=5Gi \
    --set worker.persistence.workerWork.size=10Gi \
    --wait --timeout 300s
  → Release "vteam" REVISION 8 deployed（server tag vteam-k8s-mcpfix 保留）
  （提示仅 server readinessProbe startPeriodSeconds 未知字段 warning，既有，无影响）

   /root/.local/share/opencode/opencode.db（249856B）+ -wal/-shm + repos/
   /data/keta-worker/opencode.json（keta-platform 注入）
d) 旧共享 PVC vteam-worker-home / vteam-worker-work 已被 helm upgrade 自动删除
   （模板移除该资源时 helm 3 默认删除，且 managed-nfs-storage reclaimPolicy=Delete
   → 旧数据不可恢复）。报告供决策：如需保留旧 worker 数据须在 upgrade 前手动备份/改
   reclaimPolicy；本次数据为运行时会话/缓存，丢失影响有限。
