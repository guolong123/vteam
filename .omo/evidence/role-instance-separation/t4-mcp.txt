1. notify_agent 双开发者完整实例语义（@开发者-2 命中 ta_dev_2）
--------------------------------------------------------------------------------
调用：notifyAgent({ selfInstanceId: ta_dev_1（开发者-1）, targetInstanceId: ta_dev_2（开发者-2）, content })

落库消息断言（prisma.message.create data）：
  senderId: 'a_developer'                          <- 目标实例的 agent id（查实例行）
  senderInstanceId: 'ta_dev_2'                     <- 目标实例 id（targetInstanceId）
  content.text: '@开发者-2 请处理模块B'
  mentions: [{ type:'agent', instanceId:'ta_dev_2', agentId:'a_developer', name:'开发者-2' }]

dispatchAgentMention 收到：
  { taskId, channelId, text: '@开发者-2 请处理模块B', targetInstanceId: 'ta_dev_2' }
  -> @开发者-2 命中开发者-2 实例，而非同 agent 第一实例 ta_dev_1（T3 最小适配已被本任务替换）

返回结构：{ messageId, channelId, targetInstanceId: 'ta_dev_2' }
目标实例不存在/不在团队 → 404（不落库不触发）

--------------------------------------------------------------------------------
2. task_context agentMembers 实例形状（三实例含 main 标注）
--------------------------------------------------------------------------------
task findUnique select 补 mainAgentInstanceId。
taskAgent.findMany select 补 id/alias/seq/agentId + agent{id,name,role}。

返回：
  mainAgentInstanceId: 'ta_pm_1'
  agentMembers: [
    { id:'ta_pm_1',  alias:'项目经理-1', agentId:'a_project_manager', name:'项目经理', role:'project_manager', main: true  },
    { id:'ta_dev_1', alias:'开发者-1',   agentId:'a_developer',      name:'开发者',   role:'developer',        main: false },
    { id:'ta_dev_2', alias:'开发者-2',   agentId:'a_developer',      name:'开发者',   role:'developer',        main: false },
  ]
  main 标注 = id === mainAgentInstanceId（项目经理实例 ta_pm_1）

--------------------------------------------------------------------------------
3. assertWorkerTask 按实例集合校验（防冒充）
--------------------------------------------------------------------------------
活跃执行集合 isAgentExecuting(workerId, taskId) = Set(['ta_dev_1'])：
  - selfInstanceId='ta_dev_2'（不在集合）-> 403 PLATFORM_MCP_FORBIDDEN，不落库
  - selfInstanceId='ta_dev_1'（在集合）-> 放行（走到目标查询）
回退 findFirst：session 行 select 补 taskAgentId；instanceId = session.taskAgentId ?? session.agentId；
  selfInstanceId 与 instanceId 不一致 -> 403（错误文案含 selfInstanceId）

--------------------------------------------------------------------------------
4. 存量会话兼容（session.taskAgentId NULL）
--------------------------------------------------------------------------------
session.taskAgentId=null + session.agentId=a_developer：
  assertWorkerTask 返回 session.agentId（回退）；selfInstanceId='a_developer' 通过。
  worker-dispatcher registerExecution：dispatchForTarget 传 session.taskAgentId ?? target.agentId
  （存量会话回退 agentId 登记，防旧会话防冒充失效）；unregisterExecution 注销按
  handleTaskCompleted/handleAgentStatus（sessionId 反查 taskAgentId ?? agentId）与
  startPendingWatchdog（instanceId ?? agentId）。

--------------------------------------------------------------------------------
