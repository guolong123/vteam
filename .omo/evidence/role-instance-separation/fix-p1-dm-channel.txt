F3 P1 缺陷修复（私聊频道按实例精确落库）· 证据
==============================================
日期：2026-08-13
修复：resolveChannel + privateTarget 按 taskAgentId 精确匹配私聊频道，缺省回退 agentId
附带：toMessageDto 补 senderInstanceId（platform-mcp）；前端 onSessionUpdated 状态 key 按实例

一、缺陷根因
------------
F3 实测（t_0000000011）：开发者-2 的流式处理/终态回复被写入开发者-1 私聊频道
c_0000000025（sender_instance_id=ta_0000000035），开发者-2 私聊 c_0000000026 0 条。
存量任务 t_0000000009 同样存在（T6 遗留）。

根因（F2 审查 + F3 复现双重定位）：
1) server/src/chat/worker-dispatcher.ts resolveChannel（原 :1757-1774）
   chatChannel.findFirst({taskId, agentId}) 无 taskAgentId 维度——同 agent 多实例时
   findFirst 命中最早创建的实例频道（c_25 开发者-1），终态回复/失败消息串扰。
2) server/src/workers/worker-event.ingress.ts handleMessagePartDelta privateTarget
   （原 :504-509）同样 chatChannel.findFirst({taskId, agentId})——流式中间态串扰。
T6 修复 B 只让 createDmChannel 按 taskAgentId 幂等（频道创建独立），
但消息落库的频道定位仍按 agentId findFirst，未按 taskAgentId 精确命中各自频道。

二、修复 diff 摘要
------------------
1. server/src/chat/worker-dispatcher.ts
   - resolveChannel(taskId, agentId, taskAgentId?)：taskAgentId 存在 → findFirst
     {taskId, taskAgentId} 精确匹配；缺失 → {taskId, agentId} 回退（存量兼容）；
     均未命中 → 群聊频道兜底。
   - handleTaskCompleted：sessionId 反查 session 额外提取 sessionTaskAgentId
     （session.taskAgentId ?? undefined），resolveChannel 传入——终态回复按实例落库。
   - failProcessingMessage：payload.sessionId 反查 session.taskAgentId 传入
     resolveChannel——失败消息按实例落库。
2. server/src/workers/worker-event.ingress.ts
   - privateTarget：deltaSenderInstanceId（已从 session 反查 taskAgentId）非空 →
     findFirst {taskId, taskAgentId} 精确匹配；NULL → {taskId, agentId} 回退——
     流式中间态按实例落库。
3. server/src/platform-mcp/platform-mcp.service.ts
   - toMessageDto：row 类型补 senderInstanceId，DTO 透出 senderInstanceId
     （对齐 ChatService.toMessageDto，实时广播与历史补拉展示一致）。
4. web/app/(main)/tasks/[id]/page.tsx
   - 新增 instanceIdBySessionRef（sessionId → instanceId 映射，随 agent.loading/
     agent.error/agent.status 事件填充）。
   - onSessionUpdated：状态 key 由 agentId 改 instanceId ?? agentId，清 loading
     同样按实例 key——session.updated(idle) 精确收敛目标实例（同 agent 多实例
     不再因 agentId 共用 key 收敛错位）。
   - MembersPanel：sessionStatusByAgent 读取兼容 instanceId ?? agentId。

不修（记录 learnings）：P3 类——seq 并发撞键无重试、forwardToGroup 死代码、
createDmChannel 回退并发重复频道（非验收项）。
