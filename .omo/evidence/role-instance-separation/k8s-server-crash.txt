【6. Risks / 建议】
--------------------------------------------------------------------------------
- REV14 教训：helm upgrade 只传部分 --set 时其余值回退 chart 默认（secret 重新随机 +
  镜像回退 latest + PVC/STS 规格变更被拒）。部署必须携带完整 values 或复用
  helm get values --revision N 作为基线；禁止只传单个 --set 覆盖。
- MySQL pod 曾 OOMKilled（exitCode 137，restartCount 6，512Mi limit 偏小），
  生产建议按 chart 默认 1Gi 提升 limit。
- 本次恢复使用的是 K8s 现有镜像（vteam-worker-delete / vteam-k8s-workerdel）；
  本地新代码（巡检调度器 + managedMode 迁移 20260814120000_task_managed_mode +
  question_confirm 工具）尚未构建推送部署到 K8s，后续部署时需一并执行迁移。
- ConfigMap 修复后必须 rollout restart 使容器重新注入 env（K8s 不会热更 env）。
