k8s-remove-worker-svc — 移除 worker 共享 ClusterIP Service（方案 B）
================================================================================
日期：2026-08-14  K8s ns vteam（REVISION 13）  工作区 /data/git-project/aiagents
目标：删除 chart/vteam/templates/service-worker.yaml（共享 ClusterIP :4000），
      保留 service-worker-headless.yaml（StatefulSet serviceName 必填），
      消除 serve 走负载均衡导致会话错乱的风险；分派仍走 pod 专属 headless DNS。

--------------------------------------------------------------------------------
1. Chart 变更
--------------------------------------------------------------------------------
删除：
  chart/vteam/templates/service-worker.yaml
    （原 ClusterIP Service vteam-worker :4000/serve，仅 serve 调试入口；
      server 分派已不依赖它，REV 12 headless DNS 修复后无引用）

保留（未动）：
  chart/vteam/templates/service-worker-headless.yaml
    （clusterIP: None，StatefulSet spec.serviceName 必填依赖；
     selector 与 worker pod 标签一致，port 4000/serve）

注释同步（仅注释，无渲染逻辑变化）：
  - service-worker-headless.yaml  头注：无共享 ClusterIP；serve 调试用
    `kubectl port-forward sts/vteam-worker 14000:4000`（sts 转发到 ordinal 0）
  - statefulset-worker.yaml  WORKER_ADVERTISE_HOST 注释：删除"不能使用共享
    ClusterIP 名（vteam-worker）"段，改为"worker 无共享 ClusterIP Service"
  - configmap.yaml  WORKER_ADVERTISE_HOST 注释：同步为"仅 headless，server
    经每副本上报的 headless baseUrl 直连（serve :4000 / exec :4198 同 origin）"
  - values.yaml  service.worker 段注释：仅被 headless 模板引用（端口定义），
    无共享 ClusterIP 入口；调试命令说明
  - NOTES.txt / README.md  端口表与访问方式：worker 行改 Headless；调试命令
    改为 kubectl port-forward sts/vteam-worker 14000:4000

说明：`kubectl port-forward sts/<sts>` 转发到 ordinal 0；指定副本用
      `kubectl port-forward pod/vteam-worker-1 14000:4000`。

7. Risks
--------------------------------------------------------------------------------
- worker pod 未重启，serve/会话/注册状态零中断（helm upgrade 只删 Service）。
- 共享 Service 删除瞬间若仍有进程引用 vteam-worker:4000/4198 会连接失败；
  当前 server 分派已全部使用 headless baseUrl，6m 日志无失败。
- compose 环境（aiagents-compose-*，13000/13001/14000 端口）与 K8s 环境独立，
  不受本次变更影响；14000 当前指向 compose worker 的 serve。
- 旧的 offline worker 注册记录（baseUrl http://vteam-worker:4000）保留在库中，
  未清理（非本任务范围）；如需清理可在 workers 管理页删除。
- 未 git 提交（未授权；chart/ 目录整体仍为 untracked，含 REV 8-12 改动）。
