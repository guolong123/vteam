一、根因
---------------------------------------------------------------------
调用链：platform-mcp.service.ts issueCreate(:497) → issuesService.createByAgent(args.selfInstanceId,
taskId, dto)（:509，第一参是**实例 id ta_xxx**）→ assertAgentTaskMember(taskId, agentId)

通过，issues.creator_agent_id 外键指向 agents 表（a_ 前缀），落实例 id ta_xxx 必外键失败。

二、修复 diff 摘要（issues.service.ts，不改 schema/前端）
---------------------------------------------------------------------
1) 新增私有统一解析助手 resolveAgentInstance(taskId, ref)：
   - ref 以 `ta_` 开头（实例 id）→ taskAgent.findFirst({ taskId, id: ref }) 按实例行匹配
   - 否则（模板 agent id，存量兼容）→ taskAgent.findFirst({ taskId, agentId: ref })
   - select { id, agentId, removedAt }，返回实例行（含真实模板 agent id），未命中 null
   → 全部 agent 侧方法前缀分流收敛到一处，消除散落 startsWith 判断
2) assertAgentTaskMember(taskId, agentRef)：改走 resolveAgentInstance；返回
   { status, agentId }（agentId 为实例行解析出的真实模板 agent id，供 creator 落库）
3) assertAssigneeInTeam(taskId, assigneeRef)：改走 resolveAgentInstance（原有 ta_ 前缀
   分流保留，统一到助手）
4) createByAgent(agentRef, taskId, dto)：解构 assertAgentTaskMember 返回的真实
   agentId 落库 creatorAgentId（非 selfInstanceId 原文）；assigneeInstanceId 保持
   现有逻辑精确落库
5) findAllByAgent / findOneByAgent / updateByAgent / transitionByAgent：第一参统一
   更名 agentRef（语义=实例 id 或模板 agent id），团队校验自动经修复后的
   assertAgentTaskMember 实例化
