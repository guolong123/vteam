1. 根因确认（DB 现值）
--------------------------------------------------------------------------------

服务名）；K8s 下 server 服务名为 vteam-server → worker injectMcp() 从 mcp_servers 表拉取
该 URL 注入 opencode.json，探测失败。

7. 风险与备注
--------------------------------------------------------------------------------
- worker replicas=2 时两个 pod 共享同一 vteam-worker-home PVC（NFS），并发写同一 SQLite
  opencode.db 导致数据库损坏（PRAGMA integrity_check: Tree 23 page 23 Extends off end of page；
  opencode mcp list 报 Failed query: project ... database disk image is malformed）→ 探测失败、
  mcpStatus 无法上报。修复过程临时降 replicaCount.worker=1 并删除损坏 db 重建（已恢复 connected）。
  ⚠️ 若需恢复 2 副本，须先解决 home 卷按 pod 隔离（每副本独立 PVC / StatefulSet），否则 SQLite 并发写
  必然再次损坏 opencode.db。
- compose 部署不受影响（默认仍 http://server:3000，PLATFORM_MCP_URL 未设置时行为不变）。
- seed 日志行修正：不再硬编码打印 server:3000，输出实际 platformMcpUrl。
