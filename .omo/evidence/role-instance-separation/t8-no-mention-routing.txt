T8 群聊无 @ 消息自动路由主 Agent — 行为实证（2026-08-13）
================================================================================
实现：chat.service.createMessage 步骤 2.5 —— 仅 channel.type=task_group 且
triggers 为空（用户未 @ 任何人）时，解析任务主实例并追加 trigger：
  - task.mainAgentInstanceId 优先（须在任务团队内，未 removed）
  - 缺省回退 task.mainAgentId 第一个未移除实例（taskAgent.findFirst seq 升序）
  - 主实例已 removed / 无主实例配置 / 配置不存在于团队 → 不触发（triggers 空）
  - 有 @ 消息（triggers 非空）→ 不追加；private 频道不路由
  - 命中未移除实例 → 复用 buildTrigger（按 taskAgentId 查会话 → dispatched/no_session）
  - resolveChannelAccess 的 CHANNEL_TASK_SELECT 扩展 select mainAgentInstanceId+mainAgentId

实证环境：docker compose server 容器（13000），t_0000000005 主实例=ta_0000000013
（a_developer 开发者-1，会话 s_0000000013）；t_0000000004 无主实例。
