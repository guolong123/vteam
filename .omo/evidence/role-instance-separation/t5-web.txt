一、改动文件与摘要
------------------
1. web/app/(main)/tasks/new/page.tsx（核心改造：角色勾选 → 实例列表）
   - INITIAL_CHECKED → INITIAL_ROLES=["project_manager","developer"]（决策 1：默认含项目经理）
   - 新增 InstanceDraft{key,agentId,alias,seq,roleKey} / InstancesByRole 状态模型
   - AgentOptionCard → RoleInstanceCard：角色卡片 = 头部（角色名+实例数+启用勾选）+ 实例列表
     （角色色点 + 别名行内 input + #seq + ★主 Agent 标记/☆设主 + ✕移除）+ 虚线「+添加{角色}实例」按钮
   - 主 Agent 下拉（main-agent-select）：从实例列表选择（别名（角色名）），默认 inst-project_manager-1
   - 主实例转移（FR-19 保留）：MAIN_TRANSFER_ORDER=[project_manager, product, architect, developer, tester]，
     移除/停用当前主实例 → 取优先级最高角色第一个剩余实例
   - 提交契约：agents:[{agentId, alias?}]（alias 仅显式改名时提交，服务端缺省生成）+ mainAgentId
     （主实例 key 本地临时无法匹配，传 agent 由服务端映射第一实例）
   - 已选实例徽章区（别名+角色色+★主标记）+ 创建按钮

2. web/app/(main)/tasks/[id]/page.tsx（详情页实例化）
   - TaskDetail 加 mainAgentInstanceId / instances（对齐 toTaskDto）
   - MembersPanel 按实例渲染：data-main 主标记徽章挂实例（member-main-tag ★ 主 Agent）、#seq 序号、
     key=instanceId（同 agent 多实例不冲突）、onStartDm 传 agentId（后端 dm 契约）
   - agentMembers 数据源 = task.instances（存量回退 channel.agentMembers）；agentMap 同 agent 保留首个别名
   - mentionable 按实例：name=别名（@开发者-1 与 @开发者-2 分开）、携带 instanceId/agentId
   - 发送 mentions 附带 instanceId（后端 CreateMessageDto 按 agentId 解析，instanceId 原样落库供展示）
   - TaskPanel 主 Agent 渲染实例别名（instances[].main || id===mainAgentInstanceId）
   - MessageList sender 渲染 mentions 兜底（senderNameFromMentions：notify_agent 消息 sender=目标实例，
     其 mentions.name=目标实例别名 → 显示如 开发者-2）

3. web/app/(main)/messages/[id]/page.tsx（私聊实例化）
   - 新增 taskQuery（GET /tasks/:id → instances）
   - mainAgent 解析：channel.agent（agentId）→ 匹配 taskInstances 首实例 → name=实例别名 + instanceId
   - 发送 mentions 自动附带主实例 instanceId（保持 agentId 解析契约）

4. web/app/(main)/issues/page.tsx（指派实例化）
   - 指派数据源：GET /agents → GET /tasks/:id → instances（选中任务/编辑 issue 的任务实例）
   - 下拉选项：别名（角色中文 label），value=实例 id（ta_ 前缀）；提交 assigneeInstanceId
   - 表单 state assigneeAgentId → assigneeInstanceId（编辑预填兼容旧数据回退）
   - IssueRow 指派展示：assigneeInstanceId → 本地实例映射显示别名（存量回退 agent/user 名）

5. web/src/components/ui/message-input.tsx
   - MentionableAgent 加 instanceId?/agentId?（多实例候选 key 用 instanceId ?? id，防同 agent 冲突）

6. web/src/types/issues.ts
   - IssueItem 加 assigneeInstanceId；Create/UpdateIssuePayload 加 assigneeInstanceId（保留 agentId 兼容）
