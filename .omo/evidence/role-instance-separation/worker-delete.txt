4. 真实删除实证（K8s ns=vteam）
--------------------------------------------------------------------------------
部署：docker build vteam-server:vteam-worker-delete → push → helm upgrade -n vteam REV10
      （--reuse-values --set server.image.repository/tag）

(1) online 409 回归：
    DELETE /api/v1/workers/w_vteam-worker-0 → 409
      {"code":"WORKER_ONLINE_NOT_REMOVABLE","message":"仅离线 Worker 可删除，请先停止/下线"}
    → 行保留（DB 仍在，心跳在线）

(2) offline 遗留行删除：
    DELETE /api/v1/workers/w_vteam-worker-545cfb86f7-7jbdg → 200 {"id":...,"deleted":true}
    → DB workers 表该 id 消失（8→7）

(3) offline 带关联行删除（关联清理完整实证）：
    删除前基线：w_vteam-worker-58cf4cb768-phrcl（offline）关联：
      worker_model_availabilities 7 行 / task_group_instances 2 行 /
      sessions s_0000000003（worker_id + instance_ref=ses_000e34269ffeNSagKqiwvLkiAS）
    DELETE /api/v1/workers/w_vteam-worker-58cf4cb768-phrcl → 200
    删除后 DB：
      workers 该 id 消失（7→6）
      worker_model_availabilities WHERE worker_id=该id → 0 行（硬删）
      task_group_instances WHERE worker_id=该id → 0 行（硬删）
      sessions s_0000000003 保留，worker_id=NULL + instance_ref=NULL（置空）
      agents worker_id 无指向该 worker 的行（现状无绑定，updateMany 空操作安全）

(4) offline 造出 → 删除（完整链路）：
    kubectl scale sts vteam-worker --replicas=1（停 vteam-worker-1）
    → 35s 后 API：w_vteam-worker-1 由 online 判 offline（lastHeartbeatAt 08:18:04 停滞）
    DELETE /api/v1/workers/w_vteam-worker-1 → 200
    → DB workers 6→5，该 id + wma/tgi 全清
    恢复：kubectl scale sts vteam-worker --replicas=2 → worker-1 重新注册上线（新行自动创建）

(5) 404 防护：DELETE /api/v1/workers/w_deleted_worker → 404 WORKER_NOT_FOUND

(6) 系统回归：GET /api/v1/health → {"status":"ok"}；admin/admin123 登录 → 200（roleId=r_admin）

5. 风险与备注
--------------------------------------------------------------------------------
- 权限点 workers.delete 未写入 seed 角色矩阵（admin 为 all:true 简写天然放行；
  member all:false 仅 view 拒绝写操作）。若后续引入自定义角色需显式配 workers.delete。
- 删除 worker 行会使其上历史会话的 worker_id 置空（记录保留，归属历史字段丢失）——
  属预期语义（防 FK Restrict 阻塞删除），前端 ConfirmDialog 已明示"不可恢复"。
- task_group_instances 硬删（removedAt 软删不解除 FK Restrict，必须删行）。
- 未 git 提交（未授权），改动保留在工作区。
