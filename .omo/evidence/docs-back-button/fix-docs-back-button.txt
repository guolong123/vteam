# 文档站补返回按钮
# 时间: 2026-09-23T09:34:30+08:00

## 背景
从会话页弹窗的「在文档站打开 →」跳进文档站后，文档站头部没有任何返回入口（PageWindow 只是布局壳，全站无 router.back 用例）。

## 改动（web/app/(main)/docs/page.tsx）
- 头部 docs-title 右侧（原本 space-between 但只有一个子元素、右侧空着）加「← 返回」按钮 data-testid=docs-back；
- 行为：有应用内历史（window.history.length>1）→ router.back()；直接打开/刷新（无历史）→ 回落 /teams/{teamId}/session（有 teamId）或 /board，避免 history back 把用户弹出应用。

## 验证
web tsc 0；该文件 eslint 干净；
新增 e2e 守卫：先 goto 会话页再 goto 文档站 → docs-back 可见且含「返回」→ 点击后 URL 回到 /teams/（证明返回生效）；
docs 18 passed（1 failed=预存数据漂移 cliyard）；pages 24 passed（1 failed=预存数据漂移 旧任务硬编码）。
