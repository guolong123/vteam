【5. 链路】
worker PendingQuestionDetector 检测 serve pending → 上送 SESSION_PERMISSION → server ingress 落库
pending → SSE 广播 → 前端弹窗。但：
  - serve 已无 per_ff66020650...（僵尸）：worker replyPermission → serve POST /permission/{id}/reply
    → 404 → worker handleQuestionReply catch 统一转 HTTP 400 → server permissionReply !res.ok →
    WorkerUnavailableException(503)。
  - server QuestionsService.reply 转发失败时【不落库终态、不广播收敛】→ DB 恒 pending → 前端
    GET /questions?status=pending 恒返回该记录 → 刷新永远弹窗；点允许永远 503（死循环）。

【6. 根因】
僵尸 pending（aq_0000000004）：serve 侧已无对应 requestId，但 DB 残留 pending 记录。
reply 失败链：serve 404 → worker 400 → server 503，且 server 不落终态不收敛 → 前端无限弹窗。
（对照：新鲜权限 aq_0000000005 reply 201 + resolved + 广播收敛，流程正常 → 排除 worker 不可达/
   端点错/转发 bug。）

【7. 复现次数】GET pending ×N（304/200 交替）、POST reply ×4（均 503）。

============================================================
【8. 修复】目标：弹窗不无限弹 + reply 不再 503
============================================================
a) worker/src/exec/exec-server.ts handleQuestionReply：catch 中 DriverRequestError.status===404
   → 透传 404 + code=QUESTION_EXPIRED（区分"僵尸 requestId"）；非 404 保留 400。
b) server/src/questions/questions.constants.ts：AGENT_QUESTION_STATUS 新增 EXPIRED；
   QUESTIONS_ERRORS 新增 QUESTION_EXPIRED；新增 QUESTION_PENDING_TTL_MS=30min。
c) server/src/questions/questions.service.ts：
   - reply()：转发 WorkerUnavailableException 且 message 含 "HTTP 404"（僵尸）→ expire()
     终态落库 + emit 收敛 → 抛 410 GoneException(code=QUESTION_EXPIRED)；其他错误维持 503。
   - findAll()：惰性 TTL 清理 —— pending 超 30min 自动 expire() + 收敛（GET 时触发）。
   - 新增 expire()：落库 expired + answers{expired:true,reason} + realtime.emit AGENT_QUESTION
     {resolved:true}（前端 onAgentQuestion 据此关闭弹窗）。
d) web/app/(main)/tasks/[id]/page.tsx + messages/[id]/page.tsx：questionReplyMutation onError
   中 isApiError && (status===410 || code==='QUESTION_EXPIRED') → 关闭弹窗 + 失效 questions 缓存。

【11. 风险/备注】
- 30min TTL 为产品策略：超时未回复的 question/权限自动过期关闭弹窗（serve 侧请求若仍
  存在则不自动答复，仅平台侧收敛展示）。如需更保守可调大 QUESTION_PENDING_TTL_MS。
- worker 重建会重启 serve（同容器），进行中 agent 执行中断；会话上下文 /root volume 持久化。
- 遗留 aq_0000000001/2/3 等历史 resolved/rejected 记录不受影响。
