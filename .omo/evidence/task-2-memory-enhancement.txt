[2] 实现的权限矩阵

  端点                                 全局守卫              管理员        团队成员       非成员/其他团队    无 viewer
  ----------------------------------- --------------------- ------------ -------------- ---------------- ---------
  GET    /memories                     JwtAuthGuard(全局)    全量         global∪本团队   仅 global         仅 global（fail closed）
  DELETE /memories/:id  (归档软删)     JwtAuthGuard(全局)    任意行       本团队行        403 FORBIDDEN     403 FORBIDDEN
  POST   /memories/:id/restore         JwtAuthGuard(全局)    任意行       本团队行        403 FORBIDDEN     403 FORBIDDEN
  POST   /memories/:id/purge (硬删)    JwtAuthGuard(全局)    任意行       本团队行        403 FORBIDDEN     403 FORBIDDEN
  PATCH  /memories/:id                 JwtAuthGuard + AdminGuard（保留）  —   —                —                —

  * global 行（teamId=null）写操作仅管理员；team/role 行写操作=该团队 team_user_members 成员。
  * DELETE 语义不变（软删=归档）；硬删只在新增的 purge 端点。PATCH 权限零变更（仍 AdminGuard）。

  错误码：403 MEMORY_FORBIDDEN（新增）/ 404 MEMORY_NOT_FOUND（既有）/ 409 MEMORY_RESTORE_DUPLICATE（新增）
