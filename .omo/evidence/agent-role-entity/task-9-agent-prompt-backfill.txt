2. GUARD PREDICATE (recorded verbatim; user edits preserved)
================================================================================
Each of the 7 UPDATEs is guarded by ALL of:

  WHERE `id` = '<a_xxx>'
    AND `type` = 'template'                                          -- never custom/clone
    AND SHA2(`prompt`, 256) = '<recorded pre-split sha>'             -- byte-exact factory text
    AND `prompt` LIKE '%# 角色：%'
    AND `prompt` LIKE '%## 职责%'
    AND `prompt` LIKE '%## 协同方式%'
    AND `prompt` LIKE '%团队协作规约%';                               -- all four pre-split markers

Rationale: (a) the SHA2 equality is the real user-edit guard — ANY single-character edit by a
user changes SHA2 and the row is skipped; (b) the four LIKE markers are a defense-in-depth
second signal that only ever exist in pre-split text (the post-split text contains NONE of
them, asserted in the spec and by the generator); (c) `type='template'` protects custom/clone
rows. A row that a user customized is therefore never touched.
