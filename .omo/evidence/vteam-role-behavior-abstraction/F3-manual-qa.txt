## 1. C1 — built-in policy editable via PATCH; POST/DELETE blocked

### C1c — `PATCH ep_product` (modified config) → 200 + persists
Request body (`F3-artifacts/c1-patch-body.json`) = factory `ep_product.config` with `tools.vteam_group_post=deny`, `tools.vteam_doclib=ask`.

```
$ curl -s -X PATCH .../execution-policies/ep_product -H "Authorization: Bearer $TOKEN" \
    -H 'Content-Type: application/json' -d @c1-patch-body.json -w "HTTP:%{http_code}\n"
HTTP:200
response id/type: ep_product template

$ curl -s .../execution-policies/ep_product -w "HTTP:%{http_code}\n"

```
Raw: `c1-patch-response.json`, `c1-gett-after.json`. **PASS** — 200 and persisted on re-GET.

### C1b — `DELETE ep_product` → 403
```
$ curl -s -X DELETE .../execution-policies/ep_product -w "\nHTTP:%{http_code}\n"
{"code":"POLICY_TEMPLATE_READONLY","message":"模板策略只读（seed 维护），请克隆为 custom 策略再修改"}
HTTP:403
```
Server log: `DELETE /api/v1/execution-policies/ep_product -> 403`. **PASS**.

### C1a — `POST type=template` → rejected
```
$ curl -s -X POST .../execution-policies -d '{"name":"forged","type":"template","config":{"permission":{},"correction":{}}}'
{"message":["type must be one of the following values: custom"],"error":"Bad Request","statusCode":400}
HTTP:400
```
Server log: `POST /api/v1/execution-policies -> 400`.

**C1 nuance (raw, not rationalized away):** the task text says "POST … on a template still return 403". At the HTTP surface the wire status is **400**, not 403: the global `ValidationPipe` + DTO `@IsIn(['custom'])` rejects `type:'template'` before the service runs. The service-level 403 (`POLICY_TEMPLATE_READONLY`) remains as defense-in-depth and is what the pre-existing controller spec pins. This is **pre-existing at HEAD and unchanged by this plan** (Todo 8 learnings already documented it). The security property the claim protects — a client cannot forge a new `type=template` row via POST, and cannot DELETE a built-in row — **holds**: POST is rejected (400) and DELETE is rejected (403). C1 is **PASS** with this literal-status caveat.
