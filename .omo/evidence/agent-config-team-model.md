## 关键设计决策

1. **配置改动 vs 文件类变更双轨生效**：prompt/effect/permissionScope 等配置改动作用于后续会话即可（FR-33）；技能 SKILL.md/自定义工具文件新增 v1 需重启实例（07 §10.3），v2 transform 热更新——§7.1 以 8 行表区分。
2. **「后续会话」语义澄清**：提示词变更即时生效于后续分派，进行中会话维持原提示不中断重放；与文件类变更的重启代价是两类机制。
3. **权限范围确认流闭环**：FR-36 超范围操作 → ctx.ask request → worker SSE 回流 → 控制面转成员确认 → 结果返回执行/拒绝，对齐 07 §5 权限链路第三步。
4. **主 Agent 不越权验收**：职责边界 4 条（协调权/推进/兜底/不越权验收），验收判定权在成员（FR-04/08）。
5. **会话 5 阶段**：created（入队）→ active（启动）→ active（协作）→ frozen（团队移除）→ archived（任务归档），与 13 篇状态机联动。
