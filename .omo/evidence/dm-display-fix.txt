二、问题 1：刷新后 Agent 状态（在线 ↔ 处理中）
──────────────────────────────────────────

最后一条 agent 消息 status==='processing' → setLoadingByAgent(agentId:'operating')；
同时收敛条件改为 m.status !== 'processing' 才清除残留（processing 生成中不收敛）。

验证（c_0000000006 私聊，tester Agent）：
[a] agent 已完成（最后一条 sent）→ 刷新 → AgentInfoBar 显示「在线」  ✓（多次）
[b] 最新 agent 消息临时置为 processing（DB 模拟流式中间态，created_at=now 未超时）
    → 刷新 → AgentInfoBar 显示「处理中」+ LoadingIndicator「操作中」+ 正文「生成中」 ✓
    （截图 dm-refresh-processing.png）
[c] 恢复 sent 后刷新 → 等待 SSE 补拉收敛（~12s）→ 恢复「在线」 ✓
    （SSE 补拉重放 loading 为既有时序行为，完成消息送达后 onMessage 收敛）

结论：修复生效——刷新后运行状态从 server 历史恢复，不再误显示「在线」。
