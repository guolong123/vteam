Goal   : 在既有 team/task 读 API 上暴露「成员会话当前实际绑定的 worker」
         （运行节点），与既有「偏好节点」preferredWorkerId 并列可见。

--------------------------------------------------------------------------------
0. 冻结契约（web 侧按此实现，字段名/语义两侧完全一致）
--------------------------------------------------------------------------------
字段名  : currentWorkerId
类型    : string | null
含义    : 成员**团队会话**（Session.taskId = null）的 workerId —— 即「实际运行节点」
          null = ① 成员尚无会话；② 会话存在但未绑定任何 worker
出现位置: ① GET /teams/:id  → members[].currentWorkerId
          ② GET /teams      → items[].members[].currentWorkerId
          ③ GET /tasks/:id  → instances[].currentWorkerId
          ④ GET /tasks      → items[].instances[].currentWorkerId
不变项  : preferredWorkerId 语义 / 优先级链 / 全部写路径 / prisma schema / 迁移
          —— 均未改动。

最终 JSON 形状（两个投影字段名相同、语义相同 ⇒ 前端只读一个字段即可）：
  {
    "members": [
      {
        "id": "tmm_0000000001",
        "preferredWorkerId": "w_0000000009",   // 配置偏好（既有，未改语义）
        "currentWorkerId":  "w_0000000002",   // 新增：实际运行节点
        ...
      }
    ],
    "instances": [
      {
        "id": "tmm_0000000001",
        "preferredWorkerId": "w_0000000009",   // 配置偏好（既有，未改语义）
        "currentWorkerId":  "w_0000000002",   // 新增：实际运行节点
        "sessionStatus": "running",
        "sessionId": "s_0000000041",
        ...
      }
    ]
  }

2. 实现要点
--------------------------------------------------------------------------------
server/src/teams/teams.service.ts
  * 新增 private async currentWorkerByMember(teamIds: string[]): Promise<Map<string, string|null>>
      —— 一次查询覆盖整批：
         prisma.session.findMany({
           where: { teamId: { in: ids }, taskId: null },   // 只取团队会话行
           select: { teamMemberId: true, workerId: true },
         })
      uk_sessions_team_member 唯一键只约束 task-less 行 ⇒ 每个 (teamId, teamMemberId)
      至多一行团队会话 ⇒ memberId→workerId 映射天然无歧义。
  * findOne(id)   : currentWorkerByMember([team.id])           → 1 次查询
  * findAll(...)  : currentWorkerByMember(整页 teamIds)         → 每页 1 次查询（非 N+1）
  * toTeamDto(team, currentWorkerMap?)  第二参数可选 ⇒ 既有调用方签名不变（缺省 ⇒ 全 null）
  * 成员行恒返回 currentWorkerId（拿不到就 null），绝不条件省略：
      ⚠️ 必须与 tasks.service.ts 任务实例投影同步返回，缺一处会让正确值被 null 覆盖（既有踩坑）。
