5. 间隔默认 7 天 + **让 pending 行真的改掉**（生产关键）
===================================================================
`DEFAULT_MEMORY_MAINTENANCE_INTERVAL_MS = 7*24*60*60*1000` = 604800000。

原逻辑：`existing.status === PENDING` → 直接 return，**既有 pending 行的 intervalMs
永远不会被改** —— 生产正躺着一条 intervalMs=86400000 的 pending 行，改默认值形同虚设。
新增分支：`existing.intervalMs !== intervalMs`（含 `null` 脏数据）→ `prisma.trigger.update`
写 `intervalMs` + `nextFireAt = now + intervalMs`，保留 id / fireCount / status，并记 info 日志；
一致 → 原样保留（不 update 不 schedule）。终态行删-then-重建路径与删失败语义**未动**。
`intervalMs<=0` → 仍 cancel 既有 pending 行、不排期（未动）。
