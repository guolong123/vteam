## 6. 发现问题与修复
[BUG-1] 中文文档 id 的 hash 路由失效（正文不切换）
  现象：点击文档树「交互与页面设计」后 URL 变为 #/p/agent-platform/docs/%E4%BA%A4...
        （浏览器对中文 hash 自动 percent-encode），但正文仍显示第一篇文档。
  根因：md-docs src/App.tsx parseHash() 取 docId = rest[rest.length-1] 后直接
        findProjectDoc 匹配，未 decodeURIComponent；编码后的 id 匹配失败回退默认文档。
  修复：在 6 篇文档 frontmatter 增加英文 id 字段（scanner.ts 支持 fm.id 覆盖文件名推断）：
        01-bg-goals / 02-users-scenarios / 03-req-task-chat / 04-req-agent-artifacts
        / 05-nonfunc-acceptance / 06-interaction-design
  复验：点击 4 篇文档正文均切换 PASS；直达 #/p/agent-platform/docs/interaction-design PASS。
  注：未改动 md-docs 工具源码（超出本仓库交付范围）；文档 id 变更不影响内容注入 key
      （仍按文件名）与原型嵌入（按原型 meta.id）。
