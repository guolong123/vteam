# Agent 协作平台功能测试用例 · 总览与索引

## 1. 文档定位

本套测试用例基于 **Agent 协作平台需求文档（docs/agent-platform/01~17）与已有实现**（server/web/worker，2026-08-10 compose 部署）编写，覆盖平台全部功能模块。每个功能点均提供**正向用例**（正常路径）与**反向用例**（异常/非法/越权路径），用于功能验收与回归。

配套参考：

- 需求依据：`docs/agent-platform/03-功能需求-任务与群聊协作.md`、`04-功能需求-Agent与产出物.md`、`05-非功能与验收边界.md`、`06-交互与页面设计.md`、`09-API设计.md`、`10-群聊与消息机制.md`、`11-资源与注册机制.md`、`12-产出物协议与文档库.md`、`13-任务状态机与全生命周期.md`、`14-Agent配置与虚拟团队模型.md`、`17-仓库权限与凭证机制.md`
- 已修复问题参照：`docs/agent-platform/20-E2E验证问题清单.md`

## 2. 测试环境

| 项 | 值 |
|----|----|
| Web 入口 | http://192.168.10.78:13001 |
| API 入口 | http://192.168.10.78:13000/api/v1 |

## 3. 用例编写规范

### 3.1 用例编号

统一前缀 `TC-<模块>-<三位序号>`，模块前缀见下表：

| 前缀 | 模块 | 对应实现 |
|------|------|---------|
| TC-AUTH | 认证（注册/登录/刷新/密码找回/Profile） | server/src/auth |
| TC-USER | 用户管理 | server/src/users |
| TC-ROLE | 角色与权限 | server/src/users/roles |
| TC-PRJ | 项目管理 | server/src/projects |
| TC-TASK | 任务管理（状态机/验收/归档/团队） | server/src/tasks |
| TC-CHAT | 群聊与私聊 | server/src/chat |
| TC-RT | 实时通信（SSE 事件流） | server/src/realtime |
| TC-AGT | Agent 管理 | server/src/agents |
| TC-MDL | 模型管理 | server/src/models |
| TC-SKL | 技能管理 | server/src/skills |
| TC-TOL | 工具管理 | server/src/tools |
| TC-MCP | MCP 服务器管理 | server/src/mcp-servers |
| TC-WKR | Worker 节点管理 | server/src/workers |
| TC-ART | 产出物与文档库 | server/src/artifacts |
| TC-UPL | 文件上传 | server/src/uploads |

### 3.2 用例字段

每个用例至少包含以下字段：

| 字段 | 说明 |
|------|------|
| 用例编号 | `TC-<模块>-<序号>`，全局唯一 |
| 用例名称 | 一句话描述被测行为 |
| 用例类型 | `正向` / `反向` |
| 前置条件 | 执行前必须满足的状态（登录身份、数据准备等） |
| 操作步骤 | 编号化步骤，1..N；API 用例给出方法 + 路径 + 请求体要点 |
| 预期结果 | 每步或整体可验证的预期行为（状态码、响应字段、页面表现） |

### 3.3 优先级约定

| 级别 | 含义 |
|------|------|
| P0 | 核心主流程，阻断上线（对应 FR P0） |
| P1 | 重要功能，应交付（对应 FR P1） |
| P2 | 次要/增强，可延后（对应 FR P2 / 后续迭代） |

### 3.4 反向用例覆盖维度

- 参数非法（缺失/类型错误/越界/格式错误）
- 资源不存在（404）与已删除
- 未认证（无 token / 无效 token / 过期 token）
- 越权（非管理员访问管理端点、跨项目/跨任务访问）
- 状态机非法流转（跳过前置状态、重复流转）
- 幂等与重复提交
- 并发/时序边界

## 5. 执行建议

- 每个模块文档按「正向用例 → 反向用例」组织，正向在前。
- API 用例可直接用 curl / Postman 执行；Web 用例用浏览器或 Playwright 执行。
- 涉及多模块的数据准备（登录、建项目、建任务）可在各文档「前置条件」中复用本总览 §2 的环境信息。
- 执行前注意：产出物/文件相关用例会真实写盘（uploads volume）；任务执行会真实调度 worker 与模型，耗时较长，建议按优先级分批执行。
