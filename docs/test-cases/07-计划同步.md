# 计划同步测试用例

## 1. 模块范围与环境

本文档覆盖 **计划 Tab（Plan Tab）** 与 **opencode 计划文件同步**，对应需求「vteam 只传递、不自造计划」的核心约定：

- **文件即真相**：计划正文只存在于任务工作目录 `<WORK_DIR>/tasks/<taskId>/.opencode/plans/*.md`，vteam 不落库、不建版本、不生成内容。
- **双向同步**：agent 写文件 → 计划 Tab 展示；用户上传文件 → agent 同目录可读。
- **步骤来自 opencode todo**：执行步骤经 `GET /session/{id}/todo` 只读透传，状态由 agent 用 todo 工具推进，vteam 不写。
- **不自造行为**：vteam 不增加任何改变 opencode agent 行为的门禁；提示词只说明"计划写在哪个目录"，不做额外约束。

**测试环境**

| 项 | 值 |
|----|----|
| Web 入口 | http://127.0.0.1:13001 |
| API 入口 | http://127.0.0.1:13000/api/v1 |
| Worker 执行端点 | http://<worker>:4198（容器内），宿主机调试端口随 compose 映射 |
| 管理员 | `admin` / `admin123`（角色 admin，`permissions: {all:true}`） |
| 认证方式 | JWT Bearer；access token 默认 2h |
| 任务工作目录根 | `WORK_DIR=/data/vteam-worker`（compose 环境变量） |
| 计划目录 | `<WORK_DIR>/tasks/<taskId>/.opencode/plans/` |

**冒烟命令**（登录拿 token 后用于 API 用例）：

```bash
TOKEN=$(curl -s -X POST http://127.0.0.1:13000/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"admin123"}' | jq -r .accessToken)

# 读计划（列表 + 正文一次下发）
curl -s -H "Authorization: Bearer $TOKEN" \
  http://127.0.0.1:13000/api/v1/tasks/<taskId>/plan-docs

# 写计划（上传/覆盖）
curl -s -X POST -H "Authorization: Bearer $TOKEN" -H 'Content-Type: application/json' \
  -d '{"name":"plan.md","content":"# 计划\n"}' \
  http://127.0.0.1:13000/api/v1/tasks/<taskId>/plan-docs
```

**实现差异与前置说明**（用例预期以**实际实现为准**）：

1. **计划不再经 `submit_artifact`**：产出物类型已收敛为三态 `text / doc / file`，`type:"plan"` 已被拒绝（`IsIn` 校验失败 → 400）。计划只走文件通道。
2. **读路径降级不报错**：`GET /tasks/:id/plan-docs` 定位不到 worker（团队无主 Agent / 主成员无会话 / worker 离线）时返回 `degraded:true` + `files:[]`，**HTTP 仍为 200**；写路径相反，失败抛错（用户上传必须有明确成败反馈）。
3. **目录不存在 ≠ 降级**：目录不存在返回 `degraded:false` + `files:[]`（agent 还没写过是常态）。
4. **`plan-steps` 与 `plan-docs` 相互独立**：前者来自 opencode 会话 todo，后者来自文件；两者可单独不可用。
5. **正文随列表下发**：单文件超 256KB 截断并标记 `truncated:true`，`size` 仍为真实字节数。
6. **`directory` 由服务端定位**：`POST` 请求体只接受 `{name, content}`，不接受客户端指定目录（防越权写盘）。

**关键约束（回归红线）**

```
计划正文唯一来源 = <WORK_DIR>/tasks/<taskId>/.opencode/plans/*.md
读：GET  /api/v1/tasks/:id/plan-docs   → worker GET  /plan-files?directory=
写：POST /api/v1/tasks/:id/plan-docs   → worker POST /plan-file {directory,name,content}
步骤：GET /api/v1/tasks/:id/plan-steps → worker GET  /todos?sessionId=
```
